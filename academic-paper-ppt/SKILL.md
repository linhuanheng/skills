# 学术论文 PPT 制作

该 skill 引导用户完成从论文到学术幻灯片的完整流程：论文阅读与初步总结 → 确定展示侧重点 → 详细分析 → 关联映射 → LaTeX beamer 编译。

## 核心原则

1. **每步确认**：每一步完成后必须等待用户确认，才能继续下一步。用户说"继续"或表示满意即视为确认。
2. **事实核查**：报告中出现的所有定量数字、统计结果、核心结论，必须标注出处（原文的 section/段落/图表编号），确保是可查证的。
3. **语言自适应**：PPT 输出语言默认与用户当前对话语言一致；用户可指定中/英文。总结报告的语言与用户输入一致。
4. **学术严谨**：不添油加醋，不臆造论文未声明的贡献或结论。
5. **字体统一**：除标题封面页和结尾页外，所有正文页的正文内容字体大小统一、标题字体大小统一。
6. **表格居中**：所有表格必须水平居中。
7. **内容垂直排列**：除图片可水平排列外（如并排放置两张图），其余内容必须垂直排列，不可使用多栏布局。
8. **页面防溢出**：每页 PPT 内容不能超出页面可显示区域。若内容过多必须拆分到多页，不可缩小字体硬塞。
9. **图片占位填补**：涉及图片展示的部分统一使用 `[Figure X insert here]` 占位符。在用户确认所有图片已保存在本地路径后，才用 `\includegraphics{}` 替换占位符并重新编译。

## 工作流程

### 第 1 步：接收论文并提取内容

用户提供论文的两种方式：
- **PDF 路径**：使用 `pdf` skill 读取 PDF，提取完整文本和图表标题。
- **Zotero 条目 key**：使用 `mcp__zotero-mcp__get_item_details` 获取元数据，`mcp__zotero-mcp__get_content` 获取全文（包括 PDF、笔记、摘要）。

提取后确认获取到了完整内容（文本量、图表数量、参考文献数量），报告给用户确认基础数据是否完整。

### 第 2 步：生成初步总结报告（MD）

基于全文内容，生成第一份 Markdown 报告。保存到当前工作目录的 `paper_reports/` 文件夹下。

**报告结构：**

```markdown
# [论文标题]
## 论文类型判断
- **类型**：[理论推导型 / 实证方法论型 / 实证型 / 综合型]  
- **判断依据**：[简述判断理由，1-2 句]

## 主要工作与核心贡献
- **主要工作**：[论文做了什么，3-5 句]
- **核心贡献点**：
  1. [贡献点 1]（出处：Section X, Paragraph Y）
  2. [贡献点 2]
  ...

## 内容概要
### 理论框架（如有）
[2-4 句概括，标注关键模型/假设/定理所在章节]

### 实证方法设计（如有）
[2-4 句概括，标注所用数据源、样本量、核心估计策略，引用对应 section]

### 实证结果（如有）
[2-4 句概括，标注核心系数/效应量/显著性/关键表格编号]
```

**生成后**：向用户展示报告，询问："这份初步总结是否准确？是否需要调整？" 并提示用户选择展示侧重点。

### 第 3 步：确定展示侧重点

询问用户需要在 PPT 中重点展示的方面：

> 请选择您希望在 PPT 中重点展示的内容（可多选）：
> 1. 理论框架与模型推导
> 2. 实证方法设计（识别策略、估计方法、稳健性检验）
> 3. 实证结果（基准回归、机制分析、异质性分析）
> 4. 数据与变量说明
> 5. 文献贡献与理论定位
> 6. 其他（请说明）

获得用户确认后进入第 4 步。

### 第 4 步：生成侧重内容详细报告（MD）

根据用户选择的侧重点，深入挖掘对应内容。保存到 `paper_reports/` 文件夹下。

**对于理论框架**：
- 核心假设、模型设定、关键定理/命题
- 推导逻辑链条
- 与既有理论的联系与区别

**对于实证方法设计**：
- 识别问题的来源与处理策略
- 估计方程/模型规范
- 内生性处理、稳健性检验的设计逻辑
- 数据来源、样本筛选、变量构造

**对于实证结果**：
- 基准回归结果及经济含义解读
- 机制检验的逻辑与证据链
- 异质性分析的模式与解释
- 稳健性检验的结论

**报告中必须**：
- 引用原文具体段落或图表编号
- 对每个关键数字标注其统计显著性水平
- 区分"作者原文陈述"与"基于原文的合理推断"

### 第 5 步：生成关联映射报告（MD）

生成第三份 MD 报告，建立"侧重点内容"与"文章核心贡献"之间的对应关系。保存到 `paper_reports/` 文件夹下。

**报告结构：**

```markdown
# 侧重点与核心贡献关联映射
## 整体逻辑
[简述侧重点如何支撑文章的核心贡献]

## 逐一映射
| 侧重点内容 | 对应的核心贡献 | 原文证据位置 | 支撑强度 |
|-----------|--------------|-------------|---------|
| [内容 A]  | [贡献 X]     | Section X, Table Y | 直接支撑 / 间接支撑 |
| ...       | ...         | ...         | ...     |

## 证据完整性评估
- [如果没有直接支持的贡献点，指出需要补充的证据]
```

### 第 6 步：用户确认三份报告

逐份向用户展示三份报告（或用户一次性确认全部），确认后才能进入编译阶段。用户可能要求修改 — 在此阶段反复修改直到满意。

### 第 7 步：LaTeX Beamer 编译

基于三份确认后的报告，编写 beamer `.tex` 文件并编译。

**排版规则**：
- 使用 `beamer` 文档类，学术风格主题（如 `Madrid`、`CambridgeUS`、`Boadilla` 等）
- 中文时使用 `\usepackage[UTF8]{ctex}`，选装中文字体；英文时使用标准 beamer 配置
- 结构：标题页 → 目录 → 正文分节 → 总结 → 参考文献
- 标题页包含：论文标题、作者、出处、汇报人、日期
- 正文页限制：每页 3-5 个要点，避免文字过密
- 数字/表格：关键数字用 `\alert{}` 高亮
- 参考文献：用 `\bibliography` 或 `thebibliography` 环境

**必须遵守的排版规则**（在 `.tex` 代码中严格执行）：

1. **字体统一**：在导言区统一设置正文字号（如 `\setbeamerfont{normal text}{size=\normalsize}`）和标题字号。除标题页和结尾页外，不得在任何 frame 内使用 `\small`、`\tiny`、`\Large` 等字号切换命令。
2. **表格居中**：所有 `tabular`/`table` 环境必须用 `\centering` 或 `\begin{center}...\end{center}` 包裹，禁止使用 `\raggedright`、`\flushleft` 等。
3. **垂直布局**：除图片外，所有内容（文字、表格、itemize/enumerate）必须垂直排列。图片并排可使用 `\begin{columns}`，但不得用于文字。
4. **防溢出检查**：编写每页 frame 后自查——若 `\vspace` 为负数、或 frame 内容超过可用高度（约为 `\textheight` 的 80%），必须拆分到多页。宁可拆页也不缩放文字。
5. **图片占位**：所有涉及图片展示的 frame，不直接使用 `\includegraphics{}`，而使用醒目占位符 `[Figure X insert here]`（位于独立的 frame 或 itemize 项中）。告知用户图片占位数量和编号列表后，等待用户提供本地图片路径。

**编译流程**：

- **第一阶段（占位编译）**：使用图片占位符生成 `.tex` → 运行 `pdflatex -interaction=nonstopmode <file>.tex`（中文用 `xelatex`）→ 生成不含图的 PDF 供用户检查排版
- **第二阶段（图片替换）**：用户确认图片已保存在本地并提供路径后，将 `[Figure X insert here]` 替换为 `\includegraphics[width=\textwidth]{<path>}` → 重新编译 → 生成最终 PDF

**编译注意事项**：
- 中文文档必须用 `xelatex` 编译
- 编译两遍确保目录和交叉引用正确
- 若编译失败，分析 `.log` 文件中的错误，修正后重编译（不可静默跳过）
- 编译完成后告知用户 PDF 文件路径

## 输出文件清单

完成后在 `paper_reports/` 文件夹下应有：

```
paper_reports/
├── 01_initial_summary.md      # 初步总结报告
├── 02_detailed_focus.md       # 侧重内容详细报告
├── 03_contribution_mapping.md # 关联映射报告
├── slides.tex                 # Beamer 源文件
└── slides.pdf                 # 编译后的 PPT
```

## 事实核查机制

在生成第 2、4、5 步的报告时，对以下内容必须进行原文核查：
- 所有定量数字（系数值、效应量、百分比、样本量等）
- 所有归因于原文的结论性陈述
- 图表编号和数据来源

在报告中用 `[出处: Section X, Table Y, Row Z]` 格式标注，以便用户快速定位原文核对。
