# 数据分析技能

本技能使用 Python 脚本对数据进行全面的描述性统计、缺失值分析、异常值检测、数据类型识别和自相关分析，并将分析结果保存为结构化的 Markdown 文件。

在脚本生成基础报告后，AI 会主动询问用户是否有变量说明文档，如有则根据文档内容进行语义异常值分析，并将分析结果补充至报告。

## 核心功能

### 1. 数据类型识别
- **自动识别数据类型**：横截面数据、时间序列数据、面板数据
- **时间列检测**：识别日期/时间列（列名匹配、日期类型、可解析为日期、年份列）
- **个体标识列检测**：识别个体/截面标识列（列名匹配、字符串类型、唯一值比例）
- **面板结构分析**：判断是否为平衡面板、个体数量、时间期数、观测数分布

### 2. 描述性统计分析
- 计算基本统计量：均值、中位数、标准差、最小值、最大值、四分位数
- 生成数据分布概览
- 分析数据特征和模式
- 计算偏度和峰度

### 3. 缺失值分析
- **整体缺失情况统计**：总缺失单元格数、缺失比例
- **缺失值分类**：识别完全无缺失、部分缺失、完全缺失的列
- **行缺失分布**：按每行缺失值数量统计行数分布
- **缺失值相关性分析**：识别倾向于同时缺失的列组合
- **详细列缺失信息**：每列的缺失值数量、缺失比例、非缺失值统计
- **针对性处理建议**：根据缺失程度（轻度<5%、中度 5%-20%、严重≥20%）提供不同建议

### 4. 异常值检测
- 使用 IQR（四分位距）方法检测异常值
- 报告异常值数量、比例和具体数值
- 提供正常值范围
- 提供异常值处理建议

### 5. 自相关分析（针对时间序列/面板数据）
- **自相关系数计算**：滞后 1-5 阶的自相关系数
- **Ljung-Box 检验**：检验是否存在显著的自相关
- **分析结论**：根据检验结果提供自相关性判断
- **建模建议**：针对存在自相关的数据提供建模建议（AR 项、固定效应、HAC 标准误）

### 6. 平稳性检验（针对时间序列/面板数据）
- **ADF 检验**：检验序列是否存在单位根（原假设：非平稳）
- **KPSS 检验**：检验序列是否平稳（原假设：平稳）
- **综合判断**：结合 ADF 和 KPSS 检验结果给出综合结论
- **处理建议**：针对非平稳序列提供差分、对数差分或协整分析建议

### 6. 语义异常值分析（AI 交互方式）
- **变量说明文档读取**：支持 JSON、CSV、Excel、Word、PDF 等格式
- **语义规则提取**：从文档中提取变量的合理取值范围、单位、逻辑约束
- **临时脚本分析**：根据变量说明编写临时 Python 脚本，精确定位异常数据
- **异常情况概况**：在报告中添加异常数据详细信息（行号、数据 ID、异常值等）
- **报告补充**：将语义异常值分析结果补充至 Markdown 报告

### 7. 报告生成
- 将分析结果保存为结构化的 Markdown 文件
- 包含统计表格、数据类型识别、自相关分析和可视化建议
- 生成可读性强的数据分析报告

## 使用场景

本技能适用于以下场景：
- 数据探索和初步分析
- 数据质量检查（缺失值、异常值）
- 缺失值模式分析和处理决策
- 异常值检测和处理
- 时间序列数据分析（宏观经济数据、金融数据等）
- 面板数据分析（企业数据、地区数据等）
- 生成数据报告用于分享或文档记录

## 工作流程

### 阶段一：Python 脚本分析
1. **数据准备**：用户提供数据文件（CSV、Excel 等格式）
2. **数据类型识别**：自动识别数据类型（横截面/时间序列/面板）
3. **分析执行**：
   - 计算描述性统计量
   - 分析缺失值情况（整体、分类、模式、相关性）
   - 检测统计学异常值（IQR 方法）
   - 分析自相关性（时间序列/面板数据）
4. **报告生成**：生成基础 Markdown 报告

### 阶段二：AI 交互分析（语义异常值检测）
5. **询问变量说明**：AI 主动询问用户是否有变量说明文档
6. **文档读取**：用户如有文档则提供路径，AI 读取文档（支持 JSON、CSV、Excel、Word、PDF 等格式）
7. **语义规则提取**：AI 从文档中提取每个变量的语义规则（合理取值范围、单位、逻辑约束等）
8. **临时脚本分析**：AI 编写临时 Python 脚本，根据语义规则精确定位异常数据
   - 识别超出合理范围的数据点
   - 记录异常数据的行号、ID 标识、异常值
   - 分类汇总异常情况
9. **报告补充**：AI 将以下分析结果补充至 Markdown 报告
   - 异常情况概况表（变量名、异常数量、异常类型）
   - 详细异常数据列表（行号、数据 ID、实际值、预期范围、异常类型）
   - 异常数据处理建议

## 输出内容

生成的 Markdown 报告包含以下部分：

### 1. 数据概览

- 列信息表（数据类型、缺失值数量、缺失比例）

### 2. 缺失值分析

- 数据类型判断（横截面/时间序列/面板）及置信度
- 检测到的时间列信息

- 自相关系数表（滞后 1-5 阶）

- 每列异常值数量、比例、正常值范围

- **变量说明摘要**：变量名、说明、合理取值范围
- **异常情况概况**：
  - 异常数据汇总表（变量名、异常数量、异常类型分布）
  - 异常严重程度评估（轻度/中度/严重）
- **详细异常数据列表**：
  - 行号（数据在文件中的位置）
  - 数据 ID（如有 ID 列）
  - 实际值与预期范围对比
  - 异常类型（低于最小值/高于最大值/负值异常等）
- **处理建议**：针对语义异常值的具体处理建议

### 8. 分析建议
- **缺失值处理建议**：根据缺失程度提供轻度/中度/严重缺失的处理策略
- **具体列处理建议**：针对每个有缺失的列提供建议
- **缺失模式处理建议**：针对完全缺失列、相关缺失列的建议
- **异常值处理建议**：检查数据来源、业务理解、处理方法选择
- **进一步分析建议**：根据数据类型提供针对性建议
  - 时间序列：趋势分析、平稳性检验、ARIMA 模型等
  - 面板数据：个体效应检验、时间效应检验、动态面板等
  - 横截面数据：可视化、相关性、分布检验、分组分析等

## 使用方法

### 命令行方式
```bash
cd data-analysis
python scripts/descriptive_stats.py --input your_data.csv --output report.md
```

### 参数说明
- `--input/-i`: 输入数据文件路径（支持 CSV/Excel 格式）【必需】
- `--output/-o`: 输出 Markdown 报告路径（默认：data_analysis_report.md）
- `--method/-m`: 异常值检测方法（目前仅支持 iqr）

### 示例
```bash
# 分析横截面数据
python scripts/descriptive_stats.py --input examples/sample_data.csv --output cross_section_report.md

# 分析时间序列数据
python scripts/descriptive_stats.py --input examples/time_series_data.csv --output ts_report.md

# 分析面板数据
python scripts/descriptive_stats.py --input examples/panel_data.csv --output panel_report.md

# 分析自己的数据
python scripts/descriptive_stats.py -i /path/to/your/data.csv -o output_report.md
```

## 变量说明文档格式

变量说明文档用于语义异常值分析，支持多种格式：

### JSON 格式示例
```json
{
  "variables": {
    "age": {
      "description": "受访者年龄",
      "unit": "岁",
      "min_expected": 0,
      "max_expected": 120,
      "notes": "年龄应在 0-120 岁之间"
    },
    "income": {
      "description": "年收入",
      "unit": "元",
      "min_expected": 0,
      "max_expected": 500000,
      "notes": "收入不应为负，合理上限为 50 万"
    }
  }
}
```

### CSV 格式示例
```csv
variable,description,unit,min_expected,max_expected,notes
age，受访者年龄，岁，0,120，年龄应在 0-120 岁之间
income，年收入，元，0,500000，收入不应为负
```

### 其他格式
- **Word/Excel 文档**：AI 自动读取包含变量说明的表格或文本
- **PDF 文档**：AI 自动提取变量说明信息
- **任意文本格式**：只要包含变量名、合理取值范围等信息即可
