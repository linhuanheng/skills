# 经济学模型推导指导

本 skill 指导 AI 完成详细、严谨的经济学模型推导。目标是生成高质量、可重现的 Markdown 推导文档，包含完整的经济学直觉解释。

## 核心原则

### 1. 纯理论推导导向
- **仅 Markdown 推导**：所有理论模型推导仅编写 Markdown 文档，不编写任何程序代码
- **数学严谨性优先**：强调数学推导的完整性和严谨性
- **经济直觉阐释**：所有数学结果必须提供经济学解释

### 2. 结构完整性
每个模型推导包含五个核心部分：
1. 问题背景与动机
2. 模型设定
3. 数学推导
4. 均衡分析
5. 比较静态分析

## 核心原则（详细）

1. **完整性**：每一步推导都应是可重现的
2. **透明性**：重要的假设和简化需明确说明  
3. **严谨性**：数学推导需符合标准数学规范
4. **经济直觉**：数学结果必须有清晰的经济学解释
5. **变量分类清晰**：明确区分内生变量、状态变量（外生变量）和控制变量

## 技能功能

### 基础功能

#### 1. 交互流程管理
- **执行前参数确认**：在执行推导前询问用户推导详细程度（basic/intermediate/advanced）
- **用户偏好收集**：通过 AskUserQuestion 工具收集用户对推导粒度、模型类型偏好的选择
- **工作流程定制**：根据用户选择的详细程度调整推导步骤的详细程度和文档深度

#### 2. 模型构建指导
- 帮助定义研究问题和模型框架
- 指导选择适当的经济主体、目标函数和约束条件
- **确定经济系统中的三类变量**：
  - **内生变量**：模型内部决定的变量（如消费 c、投资 i、价格 p）
  - **状态变量**：描述系统历史的状态（如资本存量 k、资产持有 s、外生冲击 z）
  - **控制变量**：决策者选择的变量（如储蓄 s、消费 c）
- 协助设定时间结构和信息结构

#### 3. 数学推导支持
- 提供标准数学符号和术语指导
- 辅助建立最优化问题（拉格朗日方法、贝尔曼方程）
- 验证一阶条件和均衡条件的推导
- 检查比较静态分析的逻辑
- **两阶段推导结构**：
  - 阶段 2.1：针对每个经济主体的决策问题进行求解，得到个体行为方程
  - 阶段 2.2：将个体行为方程代入市场均衡条件，求解整个经济系统的均衡
  - 阶段 2.3：进行比较静态分析，分析外生参数变化对均衡的影响
- **根据详细程度调整推导粒度**：
  - basic：仅显示关键步骤和最终结果
  - intermediate：显示主要推导步骤和中间结果
  - advanced：显示所有数学细节和完整推导过程

#### 4. 文档生成
- 生成符合规范的 Markdown 推导文档
- 使用 MathJax 语法渲染数学公式

### 高级功能

#### 1. 模型类型支持
- **静态优化模型**：消费者理论、厂商理论、局部均衡分析
- **动态优化模型**：最优增长模型（Ramsey 模型）、真实经济周期（RBC）模型、新凯恩斯主义模型
- **博弈论模型**：寡头竞争（Cournot, Bertrand）、信号博弈、拍卖理论
- **金融模型**：资本资产定价模型（CAPM）、套利定价理论（APT）、期权定价模型（Black-Scholes）
- **异质性代理人模型**：异质性信念模型、异质性风险厌恶模型、收入/财富分布动态模型

#### 2. 质量检查
- 自动检查模型逻辑完整性
- 验证数学推导的正确性
- 确保经济学解释的合理性
- **确保完成每个内生变量均衡时的决定方程都得到推导**

## 推导流程框架

### 前置阶段：参数确认
```
1. 询问推导详细程度（basic/intermediate/advanced）
2. 确认模型类型（根据用户需求推断或明确询问）
3. 确认输出格式要求
```

### 第一阶段：模型构建
```
1. 明确研究问题
2. 定义经济主体
3. 选择模型类型（基于前置阶段确认）
4. 明确内生变量、状态变量以及控制变量
5. 设定目标函数
6. 确定约束条件
```

### 第二阶段：数学推导（分两阶段进行）

#### 阶段 2.1：经济主体决策问题求解
```
1. 针对每个经济主体（消费者、厂商、投资者等）：
   a. 将主体的经济行为形式化为数学优化问题
   b. 建立相应的目标函数和约束条件
   c. 建立拉格朗日函数或贝尔曼方程
   d. 经济直觉描述：对目标函数、约束条件和优化问题的经济学含义进行解释
   e. 推导一阶条件（根据详细程度调整推导步骤粒度）
   f. 求解个体的最优决策规则（如需求函数、供给函数、投资规则等）
2. 获得所有经济主体的行为方程
```

#### 阶段 2.2：经济系统均衡求解
```
1. 定义市场均衡条件（商品市场出清、要素市场出清、资产市场均衡等）
2. 将经济主体的行为方程代入均衡条件
3. 求解均衡时的价格体系和资源配置
4. 推导所有内生变量的决定方程
5. 验证均衡的存在性、唯一性和稳定性（根据模型复杂度）
```

#### 阶段 2.3：比较静态分析
```
1. 对均衡系统进行全微分或线性化
2. 分析外生参数变化对内生变量的影响
3. 计算各种弹性和乘数
4. 解释比较静态结果的经济学含义
```

### 第三阶段：结果分析
```
1. 解释数学结果的经济含义
2. 分析政策含义
3. 讨论模型局限性
4. 联系实证研究
```

### 第四阶段：额外分析（或有流程）
```
1. 在完成基本推导后，询问用户是否需要进行额外分析
2. 如果用户选择"是"，询问额外分析的具体内容
3. 根据用户选择的额外分析内容，进行相应的数学推导和经济学解释
4. 将额外分析结果整合到最终的推导文档中

常见额外分析类型：
- 福利分析：计算消费者剩余、生产者剩余、社会总福利
- 效率分析：分析资源配置的帕累托效率、市场失灵问题
- 扩展模型：将模型扩展到更多经济主体、更多商品、更多时期
- 政策分析：分析税收、补贴等政策对均衡的影响
- 敏感性分析：分析关键参数变化对主要结论的影响程度
- 实证联系：讨论模型的实证检验方法和数据需求
- 计算动态路径：对于动态模型，计算均衡的动态收敛路径
```

## 变量命名规范

### 变量分类
- **内生变量**：小写字母（c, i, y, k, l 等）
- **状态变量**：通常是滞后内生变量或外生过程（k_t, s_t, z_t）
- **控制变量**：决策变量（c_t, s_t, n_t）
- **外生变量/参数**：希腊字母或大写字母（α, β, A, δ, ρ等）

### 下标约定
- **时间下标**：t, t+1, t-1
- **个体下标**：i, j
- **商品下标**：1, 2, ..., N

### 函数表示
- 效用函数：U(c₁, c₂) 或 u(c)
- 生产函数：F(K, L) 或 f(k)
- 利润函数：π(p, w, r)
- 价值函数：V(s) 或 J(k)

## 常见模型类型与求解方法

### 1. 静态优化模型
**典型问题**：消费者效用最大化、厂商利润最大化

**变量分类示例**（消费者问题）：
- 控制变量：c₁, c₂（消费选择）
- 外生变量：p₁, p₂（价格）, m（收入）
- 内生变量：在给定价格下的 c₁*, c₂*

**两阶段求解过程**：
1. **个体决策求解**：使用拉格朗日方法求解消费者效用最大化问题，得到马歇尔需求函数 c₁* = f(p₁, p₂, m), c₂* = g(p₁, p₂, m)
2. **系统均衡求解**：将需求函数代入市场出清条件（如给定供给等于需求），求解均衡价格（如果有多个市场）

**均衡条件**：边际替代率 = 相对价格

### 2. 动态优化模型
**典型问题**：最优增长、RBC 模型

**变量分类示例**（Ramsey 模型）：
- 状态变量：k_t（资本存量）
- 控制变量：c_t（消费）
- 内生变量：k_{t+1}, c_t, r_t, w_t

**两阶段求解过程**：
1. **个体决策求解**：代表性家庭最大化跨期效用，建立贝尔曼方程或拉格朗日问题，推导欧拉方程：u'(c_t) = β(1+r_{t+1})u'(c_{t+1})
2. **系统均衡求解**：将欧拉方程与厂商利润最大化条件（边际产出等于要素价格）、市场出清条件（c_t + i_t = f(k_t)）结合，求解均衡动态路径

**求解方法**：贝尔曼方程或拉格朗日方法（带无穷期）

**关键方程**：欧拉方程、横截性条件、资源约束

### 3. 博弈论模型
**典型问题**：寡头竞争、信号博弈

**变量分类示例**（Cournot 模型）：
- 控制变量：每个厂商选择自己的产量 q_i
- 内生变量：均衡产量 q_i*, 均衡价格 p*
- 外生变量：a, b（需求参数）, c（边际成本）

**两阶段求解过程**：
1. **个体决策求解**：每个厂商 i 在给定其他厂商产量下，求解利润最大化问题，得到最优反应函数 q_i = R_i(q_{-i})
2. **系统均衡求解**：联立所有厂商的反应函数，求解纳什均衡 (q_1*, q_2*, ..., q_n*)，然后代入需求函数得到均衡价格 p*

**求解方法**：纳什均衡（反应函数法）

### 4. 金融模型
**典型问题**：资产定价、投资组合选择

**变量分类示例**（Lucas 树模型）：
- 状态变量：s_t（树份额持有）
- 控制变量：c_t, s_{t+1}（消费和资产持有决策）
- 内生变量：p_t（树价格）
- 外生变量：y_t（资源禀赋过程）

**两阶段求解过程**：
1. **个体决策求解**：代表性投资者最大化期望跨期效用，建立随机贝尔曼方程，推导欧拉方程：p_t u'(c_t) = βE_t[u'(c_{t+1})(p_{t+1}+d_{t+1})]
2. **系统均衡求解**：将均衡条件（c_t = y_t, s_t = 1）代入欧拉方程，得到资产定价公式：p_t = βE_t[u'(y_{t+1})/u'(y_t) (p_{t+1}+d_{t+1})]

**求解方法**：随机动态规划、资产定价公式

## 使用示例

### 示例 1：构建消费者选择模型

**用户**: "构建一个消费者在预算约束下效用最大化的静态模型"

**Skill 交互流程**:
1. **询问推导详细程度**：使用 AskUserQuestion 工具询问用户希望推导的详细程度（basic/仅显示关键步骤，intermediate/显示主要推导步骤，advanced/显示所有数学细节）
2. **确认模型类型**：根据用户请求，确认使用静态优化模型框架
3. **阶段 2.1：消费者决策问题求解**
   a. 确定控制变量为消费束 {c_i}, i=1,2,...,N
   b. 确定内生变量为消费 c_i, i=1,2,...,N
   c. 确定外生变量为商品价格 p_i, i=1,2,...,N, 收入 W
   d. 指导定义效用函数 U({c_i})，采用 Cobb-Douglas 形式
   e. 帮助建立预算约束 p₁c₁ + p₂c₂ ≤ W
   f. **经济直觉描述**：解释效用函数反映消费者对不同商品组合的偏好，预算约束反映消费者的收入限制和市场价格条件
   g. 辅助建立拉格朗日函数
   h. 推导一阶条件（根据所选详细程度控制推导步骤粒度）
   i. 求解消费者的马歇尔需求函数：c₁* = f(p₁, p₂, W), c₂* = g(p₁, p₂, W)
4. **阶段 2.2：均衡分析（简化）**
   a. 解释在给定价格 p₁, p₂ 和收入 W 下，消费者决策即为均衡解
   b. 讨论市场出清条件（消费者需求等于给定供给）
5. **阶段 2.3：比较静态分析**
   a. 分析价格变化对需求的影响（替代效应和收入效应）
   b. 分析收入变化对需求的影响（恩格尔曲线）
6. **阶段 4：额外分析询问**
   a. 询问用户是否需要进行额外分析："模型的基本推导已完成。您是否需要进行额外的分析（如福利分析、效率分析、扩展模型等）？"
   b. 如果用户选择"是"，询问额外分析的具体内容："请描述您希望进行的额外分析内容。"
   c. 根据用户输入进行相应的数学推导和经济学解释
7. 生成完整的 Markdown 推导文档，明确区分各阶段推导

### 示例 2：推导卢卡斯树模型

**用户**: "假设有这样一个经济系统，该系统中只有每一期都随机产生资源的'树'这一个资产，每一期消费者决定当期的消费以及以价格 p_t 购入一定份额 s_(t+1) 的'树'，我们现在关心这个系统均衡时的状态，并分析重要变量是如何由这个系统所决定的。"

**Skill 交互流程**:
1. **询问推导详细程度**：使用 AskUserQuestion 工具询问用户希望推导的详细程度（basic/仅显示关键步骤，intermediate/显示主要推导步骤，advanced/显示所有数学细节）
2. **确认模型类型**：根据用户请求，确认使用动态均衡模型框架
3. **阶段 2.1：消费者决策问题求解**
   a. 确定控制变量为当期的消费 c_t 以及下一期持有"树"的份额 s_(t+1)
   b. 确定状态变量为持有"树"的份额 s_t，外生变量为每一期的资源禀赋 y_t
   c. 确定内生变量为"树"价格 p_t
   d. 指导确定使用贝尔曼方程，其中效用函数为 CRRA 形式：u(c_t) = c_t^{1-γ}/(1-γ)
   e. 建立消费者优化问题：max_{c_t, s_{t+1}} E_t[∑_{τ=0}^∞ β^τ u(c_{t+τ})]
   f. 建立预算约束：p_t s_{t+1} + c_t ≤ y_t + p_t s_t + d_t s_t（其中 d_t 为股息）
   g. **经济直觉描述**：解释效用函数反映消费者的风险厌恶程度和时间偏好，预算约束反映消费者在当期的消费和未来资产持有之间的权衡
   h. 推导贝尔曼方程和一阶条件（根据所选详细程度控制推导步骤粒度）
   i. 求解消费者的欧拉方程：u'(c_t) = βE_t[u'(c_{t+1})(p_{t+1}+d_{t+1})/p_t]
4. **阶段 2.2：经济系统均衡求解**
   a. 定义市场均衡条件：商品市场出清（c_t = y_t），资产市场出清（s_t = 1）
   b. 将均衡条件代入欧拉方程，得到资产定价方程
   c. 求解均衡时的树价格 p_t 作为外生过程 y_t 的函数
   d. 推导风险溢价公式和资产收益率特征
5. **阶段 2.3：比较静态分析**
   a. 分析风险厌恶系数 γ 变化对风险溢价的影响
   b. 分析折现因子 β 变化对资产价格水平的影响
   c. 分析资源禀赋 y_t 的波动性对资产价格波动的影响
6. **阶段 4：额外分析询问**
   a. 询问用户是否需要进行额外分析："模型的基本推导已完成。您是否需要进行额外的分析（如福利分析、效率分析、扩展模型等）？"
   b. 如果用户选择"是"，询问额外分析的具体内容："请描述您希望进行的额外分析内容。"
   c. 根据用户输入进行相应的数学推导和经济学解释
7. 解释欧拉方程的经济学含义，生成完整的 Markdown 推导文档，明确区分各阶段推导

## 故障排除

### 常见问题

#### 1. 数学推导逻辑错误
**症状**: 一阶条件或均衡条件不正确

**解决方案**:
- 重新检查目标函数和约束条件
- 验证拉格朗日函数或贝尔曼方程的建立
- 逐步检查数学推导步骤

#### 2. 变量分类混淆
**症状**: 无法正确区分内生变量、状态变量和控制变量

**解决方案**:
- **内生变量**：由模型内部决定的变量（通过均衡条件决定）
- **状态变量**：描述系统历史/初始状态的变量（决策前已知）
- **控制变量**：决策者在当期可以选择的变量

#### 3. 经济学解释不清晰
**症状**: 数学结果缺乏经济学含义

**解决方案**:
- 为每个数学结果提供经济学解释
- 联系实际经济现象
- 讨论政策含义

## 交互参数与选项

### 交互式参数收集
本 skill 在执行推导工作前会通过 AskUserQuestion 工具收集以下参数：

#### 1. 详细程度控制
**选项**：
- **basic** (仅显示关键步骤)：适合快速了解模型结构和主要结果
- **intermediate** (显示主要推导步骤)：适合大多数学习和研究需求，显示主要推导步骤
- **advanced** (显示所有数学细节)：适合深入研究和教学，显示完整的数学推导过程

**交互方式**：
- 使用 AskUserQuestion 工具询问用户："请选择推导的详细程度"
- 根据用户选择调整后续推导步骤的粒度和文档深度

#### 2. 模型类型确认
**选项**：
- **static**：静态优化模型（消费者理论、厂商理论）
- **dynamic**：动态优化模型（最优增长、RBC模型）
- **game**：博弈论模型（寡头竞争、信号博弈）
- **finance**：金融模型（资产定价、投资组合）
- **heterogeneous**：异质性代理人模型

**交互方式**：
- 根据用户请求自动推断模型类型，或在不确定时通过询问确认
- 影响推导方法和文档结构

#### 3. 输出格式确认
**当前支持格式**：
- **markdown**：生成 Markdown 推导文档

#### 4. 额外分析选项
**选项**：
- **自动跳过**：完成基本推导后不询问额外分析
- **询问用户**：完成基本推导后询问用户是否需要进行额外分析

**交互方式**：
- 使用 AskUserQuestion 工具在完成基本推导后询问用户
- 如果用户选择"是"，再询问额外分析的具体内容
- 根据用户输入进行相应的推导

### 参数对工作流程的影响

#### 详细程度控制的影响：
- **basic 模式**：
  - 数学推导只显示关键步骤（如：建立优化问题 → 一阶条件 → 结果）
  - 跳过中间代数推导细节
  - 文档侧重于经济学解释和主要结论
  
- **intermediate 模式**：
  - 显示主要推导步骤和重要中间结果
  - 包含必要的代数推导
  - 平衡数学严谨性和可读性
  
- **advanced 模式**：
  - 显示所有数学细节和完整推导过程
  - 包含所有代数运算步骤
  - 适合教学和深入研究

## 最佳实践

### 1. 模型设计
- 从简单模型开始，逐步增加复杂性
- 明确所有假设的合理性和局限性
- 保持模型内部逻辑的一致性

### 2. 变量分类
- **在模型设定阶段明确三类变量**
- 确保内生变量数量与独立方程数相等（计数规则）
- 状态变量必须遵循转移方程

### 3. 数学推导
- 使用标准数学符号和术语
- 逐步展示推导过程，避免跳跃
- 重要步骤提供注释和解释

### 4. 文档编写
- 遵循统一的文件组织和命名规范
- Markdown 文档包含完整的结构
- 保持公式和文本的清晰排版

### 5. 结果呈现
- 为所有内生变量提供决定方程
- 提供经济学解释和政策含义
- 讨论模型的实证检验方法
